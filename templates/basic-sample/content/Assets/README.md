# Assets

`Textures/Player.png` is a 32×32 placeholder that ships with CNA Studio, under this repository's
own licence — it is the same image the `examples/HelloSprites` project uses, and it is here so that
a new project draws *something* rather than opening on an empty blue screen. Replace it.

Everything you drop in this directory is scanned by CNA Studio and given a `.cnaasset` sidecar
carrying its id, so moving a file breaks no scene.
